# Arte Naval - cobertura por capítulo

Referência: `BIBLIOGRAFIA - FINAL.pdf`, Anexo 2-B, item II - Arte Naval.

## Política do banco

- mínimo obrigatório: 25 questões por capítulo;
- alvo recomendado: 40 questões por capítulo;
- faixa preferencial: 25 a 50 questões;
- um capítulo só é marcado como coberto quando a obra correspondente está disponível para conferência;
- cada questão registra matéria, obra, capítulo, seção, módulo e assunto.
