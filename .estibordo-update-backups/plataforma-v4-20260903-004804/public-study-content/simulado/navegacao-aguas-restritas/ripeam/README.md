# RIPEAM Trainer

Aplicação web estática para estudo do RIPEAM-72.

## Estrutura

```text
ripeam/
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/app.js
└── README.md
```

## Conteúdo

- Regras 1 a 38
- Governo e navegação
- Situações no visual
- Visibilidade restrita
- Luzes e marcas
- Sinais sonoros
- Cartões específicos para sinais clássicos de prova
- Modo prova
- Busca e filtros
- Cartões difíceis
- Repetição de erros
- Estatísticas e progresso via localStorage
- Modo escuro
- Layout responsivo para celular

## Publicação no mesmo repositório do CIS

Copie a pasta `ripeam` para a raiz do repositório atual:

```text
flashcard_cis/
├── index.html              # CIS atual
├── assets/                 # assets do CIS
├── README.md
└── ripeam/
    ├── index.html
    └── assets/
        ├── css/style.css
        └── js/app.js
```

O RIPEAM ficará disponível em `/ripeam/` sem interferir no CIS.

## Fonte de estudo

Conteúdo estruturado a partir dos PDFs RIPEAM fornecidos pelo usuário, incluindo o regulamento e os quadros de Regras de Governo e Navegação, Sinais Sonoros/Luminosos e Luzes/Marcas.

Este projeto é material de estudo e não substitui a consulta ao texto integral e vigente do RIPEAM.
